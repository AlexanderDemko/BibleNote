Заметки о Писании — рядом с самим Писанием

BibleNote читает ваши тетради OneNote, находит в них ссылки на стихи и позволяет открыть нужную запись прямо из текста Библии. Кэш, разметка и поиск работают локально, на вашем компьютере.

Что делает программа

Годы заметок в OneNote превращаются в связанный со Священным Писанием справочник, которым можно пользоваться во время чтения.

Локальный индекс заметок

Полная копия тетрадей OneNote в базе SQLite на вашем диске с полнотекстовым индексом FTS5. Поиск по тысячам страниц отвечает мгновенно и работает без интернета.

Ссылки на стихи

Программа разбирает ссылки на Писание в каждом абзаце заметок и запоминает их. По любому стиху можно найти все страницы, где он упоминается.

Параллельные места

Ссылки, встречающиеся в одном абзаце и рядом друг с другом, связываются между собой с учётом веса. Так из ваших же записей вырастает карта параллельных мест с индексом параллельности.

Индуктивная разметка

Выделите слово или фразу и отметьте её смыслом: ключевое слово, Бог, Христос, Дух Святой, время, место, сравнение, противопоставление, вывод, повеление. Свои стили можно добавить.

Чтение и сравнение переводов

Встроенная читалка открывает главу в основном переводе и позволяет сравнить её ещё с двумя. Наблюдения по главе собираются в отдельную панель и экспортируются.

Доступ для ИИ-агентов

Встроенный MCP-сервер отдаёт кэш заметок ассистентам вроде Claude Code или Codex: поиск, чтение страниц, поиск по библейской ссылке и параллельным местам.

Данные остаются у вас

У BibleNote нет своего сервера, учётных записей и подписки. Программа работает с вашими файлами на вашем компьютере.

  • Где лежит кэш заметок Файл ~/BibleNote/onenote-cache.sqlite. Его можно удалить и пересобрать в любой момент.
  • Где лежит ваша разметка Отдельный файл ~/BibleNote/biblenote-user.sqlite, который переживает полное пересоздание кэша.
  • Доступ к OneNote Только на чтение: разрешения Notes.Read.All, User.Read и offline_access. Программа ничего не изменяет в ваших тетрадях.
  • Без учётной записи Microsoft Режим классического OneNote читает открытые на компьютере тетради напрямую, вход в Microsoft при этом не требуется.
  • Телеметрия Программа не отправляет статистику использования и не требует подключения к интернету после синхронизации.

С чего начать

От установки до первого поиска по заметкам — четыре шага.

  1. Установите программу

    Установщик для Windows или портативная сборка одним файлом. Отдельно устанавливать .NET или Node не нужно — всё уже внутри.

    Перейти к загрузке

  2. Выберите источник заметок

    Microsoft Graph — работает без установленного OneNote и требует входа в учётную запись. Классический OneNote — читает уже открытые тетради через COM, без входа.

  3. Выполните первую синхронизацию

    Первый проход скачивает содержимое страниц и потому идёт долго. Дальше работает инкрементальная синхронизация, которая проверяет только изменившиеся разделы.

  4. Изучайте

    Ищите по тексту заметок, открывайте страницы по библейской ссылке, читайте главу с разметкой и смотрите параллельные места, собранные из ваших же записей.

Ваши заметки — для ИИ-ассистента

BibleNote содержит MCP-сервер, который открывает локальный кэш заметок совместимым ассистентам. Ассистент ищет по вашим тетрадям и цитирует их, но по-прежнему ничего не изменяет в OneNote.

Доступны инструменты поиска по кэшу, чтения страницы, поиска страниц по библейской ссылке и подбора параллельных ссылок.

[mcp_servers.onenote]
command = "node"
args = ["C:/.../dist/server.js"]
startup_timeout_sec = 20
tool_timeout_sec = 120

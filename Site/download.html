Портативная сборка

Один файл без установки — удобно скопировать на другой компьютер. При каждом запуске распаковывается во временную папку, поэтому стартует заметно медленнее установленной версии.

Что нужно для работы

  • Операционная система Windows 10 или Windows 11, 64 бита.
  • .NET и Node.js Устанавливать отдельно не нужно: .NET-приложение собрано самодостаточно, Node входит в комплект.
  • Режим Microsoft Graph Учётная запись Microsoft — личная или рабочая. Установленный OneNote при этом не требуется.
  • Режим классического OneNote Настольный OneNote 2010, 2013 или 2016 с открытыми тетрадями. Вход в учётную запись Microsoft не нужен.
  • Место на диске Зависит от объёма тетрадей: кэш хранит текст всех страниц, а при желании и их исходный HTML.

Первый запуск

Сборки пока не подписаны сертификатом, поэтому Windows SmartScreen может показать предупреждение «Система Windows защитила ваш компьютер». Чтобы продолжить, нажмите «Подробнее», затем «Выполнить в любом случае».

Проверить целостность скачанного файла можно в PowerShell:

Get-FileHash '.\BibleNote Setup 4.0.51.exe' -Algorithm SHA256

Полученное значение должно совпадать с контрольной суммой, опубликованной на странице релиза.

После установки откройте раздел настроек, выберите источник заметок и запустите первую синхронизацию — подробности в документации.

Другие платформы

macOS. Экспериментальная сборка для Apple Silicon собирается из исходного кода. Интеграция с классическим OneNote в неё не входит: она доступна только в Windows.

Linux. Готовых сборок нет.

Сборка из исходников. Инструкции — в репозитории проекта на GitHub.

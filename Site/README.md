# Site

Публичный сайт BibleNote — статический, без сборщика и зависимостей. Любой файл можно открыть
двойным кликом, а папку целиком выложить на статический хостинг как есть.

## Структура

```text
Site/
  index.html      лендинг
  download.html   загрузка
  docs.html       документация одной страницей с оглавлением
  privacy.html    политика конфиденциальности
  terms.html      условия использования
  404.html        страница не найдена
  robots.txt      sitemap.xml
  _headers        заголовки для Cloudflare Pages
  _redirects      переадресация со старых адресов v3
  assets/         styles.css, site.js, favicon.ico, logo.png, screenshots/
```

Шапка и подвал скопированы в каждый файл — это осознанная цена отказа от сборщика. Если страниц
станет больше десяти или появится английская версия, имеет смысл перейти на Astro: разметка
переносится в компоненты почти без правок.

## Локальный просмотр

Достаточно открыть `Site/index.html` в браузере. Если нужен http-адрес:

```bash
python -m http.server 4555 --bind 127.0.0.1
```

Страница `404.html` ссылается на файлы от корня сайта (`/assets/...`), потому что хостинг отдаёт её
в ответ на произвольный адрес. При открытии с диска её оформление не подхватится — это нормально.

## Публикация

**Cloudflare Pages.** Подключите репозиторий, корневая папка сборки — `Site`, команда сборки
пустая. Файлы `_headers` и `_redirects` подхватываются автоматически.

**GitHub Pages.** Публикуйте папку `Site` из ветки. `_headers` и `_redirects` там не работают —
переадресацию придётся делать иначе.

Домен `biblenote.pro` сейчас обслуживает сайт третьей версии. Перед переключением DNS соберите
список проиндексированных адресов старого сайта и заполните `_redirects`.

## Что заменить перед публикацией

- **Адрес почты.** В `privacy.html` и `terms.html` указан `support@biblenote.pro` — заведите этот
  ящик или впишите свой. Рабочий контакт нужен и для экрана согласия Microsoft.
- **Ссылки на загрузку.** Кнопки на `download.html` ведут на
  `https://github.com/AlexanderDemko/BibleNote/releases/latest`. В репозитории пока нет ни одного
  релиза — до его публикации ссылки открывают пустую страницу. После первого релиза можно заменить
  их на прямые ссылки на файлы `BibleNote Setup <версия>.exe` и `BibleNote <версия>.exe`.
- **Контрольные суммы.** На странице загрузки описана проверка SHA256; сами суммы публикуйте в
  описании релиза.
- **Снимки экрана.** Сейчас на главной схематичный макет интерфейса, собранный из HTML. Реальные
  снимки положите в `assets/screenshots/` и замените блок `.mock` в `index.html`.
- **Юридические тексты.** `privacy.html` и `terms.html` написаны по фактическому поведению
  программы, но перед публикацией их стоит перечитать и при необходимости дополнить сведениями о
  правообладателе.

## Обновление версии

Номер версии указан в трёх местах: дважды в `index.html` (подпись под кнопками и текст последней
кнопки) и один раз в `download.html` (подзаголовок и имена файлов). При выпуске новой версии
обновите их, а также дату в `sitemap.xml`, если она появится.

## Оформление

Тема оформления повторяет палитру индуктивной разметки самой программы: жёлтый — ключевое слово,
фиолетовый — Бог, синий — время, зелёный — место, коралловый — противопоставление. Цвета заданы
переменными в начале `assets/styles.css` и отдельным набором для тёмной темы. Тёмная тема
включается по системной настройке, переключатель в шапке запоминает выбор в `localStorage`.

Внешних шрифтов, библиотек и аналитики нет намеренно: страницы открываются одинаково быстро при
любом качестве соединения.
